Overview

This course provides a comprehensive overview of Securing Kong Gateway Runtime, focusing on authentication, rate limiting, and secrets management. It emphasized the use of Kong Gateway and its plugins to enhance API security and manage traffic effectively.

Course Agenda

  1. Securing API Services
  2. Rate Limiting
  3. Authentication
  4. JWT Authentication Plugin
  5. mTLS Plugin
  6. Secrets Management
  7. Hardening the Kong Data Plane

Learning Objectives

Upon completion of this lesson, you should be able to:

  1. Understand how to secure the data plane and APIs on Kong.
  2. Deploy and configure the rate-limiting plugin.
  3. Configure Authentication with the JWT and Mutual TLS plugins.
  4. Identify some general Kong data plane hardening measures.
