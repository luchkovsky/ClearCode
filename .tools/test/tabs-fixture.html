Securing Kong Gateway Runtime

Securing Kong Gateway Runtime can be broadly classified into two categories, covering both the transport layer and the application layer of your deployed APIs.

  • Securing the Data Plane: Protecting the communication channel between client and API.
  • Securing API Services: Access control and usage enforcement at the application layer.
