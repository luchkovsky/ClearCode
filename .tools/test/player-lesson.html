What is the Rate Limiting ?

Rate limiting in an API is a mechanism that controls how many requests a client (you or your application) can make to the API within a specific time frame—such as per second, per minute, or per day.

It is used to prevent abuse, reduce load, and ensure fair usage of your services.

Shared services need to protect themselves from excessive use, so rate limiting on both client and server sides is crucial to avoid impact on availability and cascading failures.

Counter Storage Policies

Counter storage policies control how Kong stores request counters, and can have ramifications based on the use-case.
